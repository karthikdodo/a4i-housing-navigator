# UI API and A2UI surfaces

**Owners:** api/ — Karthik & Sid · ui/ — Selvan
**Protocol:** [A2UI](https://a2ui.org) v1.0 (Google's Agent-to-User Interface protocol), rendered with `@a2ui/react` 0.15 + `@a2ui/web_core` 0.15
**Agent side:** [`AGENT_REQUIREMENTS.md`](AGENT_REQUIREMENTS.md)

The browser talks to one FastAPI service. The service runs the ADK `navigator` agent and describes every panel of the workspace as an **A2UI surface**: a fixed component tree plus a JSON data model. The browser renders surfaces with the A2UI React renderer and sends user interactions back as A2UI `action` messages. Chat text, tool status and the brief JSON travel alongside, using the event types from [`ARCHITECTURE.md`](ARCHITECTURE.md#websocket-contract).

```
ui/ (React)                                   api/ (FastAPI)
┌──────────────────────────┐   WS /ws         ┌────────────────────────────────────┐
│ MessageProcessor         │◄── a2ui ─────────│ surfaces.py  component trees       │
│  + navigator catalog     │◄── status/message│ view.py      CaseState → data model│
│ A2uiSurface × 6          │◄── brief / case  │ workspace.py chat, actions, cases  │
│ chat (markdown + chips)  │── user_message ─►│ runners.py   LiveRunner (ADK) /    │
│                          │── a2ui_action ──►│              MockRunner (replay)   │
└──────────────────────────┘                  └────────────────────────────────────┘
```

## Run it

```bash
# API (repo root)
python3 -m venv .venv && .venv/bin/pip install -r api/requirements.txt -r agent/requirements.txt
gcloud auth application-default login                       # live mode only
.venv/bin/uvicorn api.main:app --reload --port 8080          # live agent (falls back to demo if ADK can't load)
A4I_AGENT_MODE=mock .venv/bin/uvicorn api.main:app --port 8080   # demo replay, no GCP

# UI
cd ui && npm install && npm run dev                          # http://localhost:5173, proxies /api and /ws to :8080
npm run build                                                # ui/dist, served by the API at /
```

| Env var | Default | Meaning |
|---|---|---|
| `A4I_AGENT_MODE` | auto | `live` (ADK agent, fail if it can't load), `mock` (replay `api/fixtures/demo_int_1142.json`), unset = live with mock fallback |
| `A4I_MOCK_DELAY` | `0.35` | Seconds between replay steps |
| `A4I_CORS_ORIGINS` | `http://localhost:5173,…` | For a UI served from another origin |
| `A4I_UI_DIST` | `ui/dist` | Built UI the API serves |

Demo mode only has recorded data for **INT-1142** (600 Block John Muir Dr). Its rows are real (from `data/`); similarity scores are fixed. The header shows **Demo replay · not live BigQuery** so it can't be mistaken for a live run.

## WebSocket `/ws`

Every frame is one JSON object. The client picks a `session_id` (kept in `localStorage`) and sends it on every frame.

**Client → server**

| `type` | Fields | Effect |
|---|---|---|
| `hello` | `session_id` | Server replies with an `a2ui` event holding `createSurface` for all six surfaces, then a `case` event with the transcript. Send on every (re)connect, with a fresh `MessageProcessor`. |
| `user_message` | `session_id`, `text` | One agent turn. |
| `a2ui_action` | `session_id`, `message` = `{"version": "1.0", "action": {name, surfaceId, sourceComponentId, timestamp, context}}` | An A2UI v1.0 renderer-to-agent action, exactly as the renderer produced it. |
| `a2ui_error` | `session_id`, `message` | Renderer validation errors; logged. |

**Server → client**

| `type` | Fields | When |
|---|---|---|
| `a2ui` | `messages: [...]` | A2UI v1.0 agent-to-renderer messages (`createSurface`, `updateDataModel`). Pass straight to `processor.processMessages`. |
| `status` | `tool`, `text`, `done?` | A tool started (`done` absent) or finished with a summary (`done: true`, e.g. "3 kept · 4 excluded"). |
| `message` | `text`, `final` | Agent text. Chunks have `final: false`; the `final: true` frame is the **whole** reply: replace the chunks with it. |
| `brief` | `brief` | Brief JSON (shape in ARCHITECTURE.md + R11–R16). |
| `case` | `case_id`, `mode`, `transcript` | The open case changed: redraw the chat from `transcript`. |
| `user_echo` | `text` | A button became a chat question (e.g. **Ask why**): show it as a user bubble. |
| `error` | `text` | Show inline; the turn still ends. |
| `turn_end` | | Re-enable the composer. |

| Method & path | Returns |
|---|---|
| `GET /health` | `{status, agent_mode, sessions}` |
| `GET /api/config` | Agent mode, A2UI version, catalog id, surface ids |
| `GET /api/a2ui/catalog` | The navigator catalog definition (A2UI v1.0 catalog JSON: basic catalog + navigator components). Generated by `npm run catalog:export`. |
| `POST /api/sessions` `{session_id?}` | `{session_id, active_case, agent_mode}` |
| `GET /api/sessions/{sid}` | Active case state |

| `GET /api/sessions/{sid}/cases` | Intake queue |
| `GET /api/sessions/{sid}/cases/{cid}` | Case: facts, brief, memo, transcript |
| `GET /api/sessions/{sid}/cases/{cid}/brief` | Brief JSON (404 until submitted) |
| `GET /api/sessions/{sid}/cases/{cid}/memo.md` | Memo download |

## Surfaces

All surfaces use catalog `https://a4i-housing-navigator.dev/a2ui/v1/navigator_catalog.json`: the A2UI v1.0 basic catalog (Column, Row, Text, Button, TextField, DateTimeInput, ChoicePicker, …) derived with the navigator components below. The component trees are fixed (`api/a2ui/surfaces.py`); only data models change (`api/a2ui/view.py`), always as a whole-surface `updateDataModel` at `/`.

| Surface id | Zone | Shows | Actions it sends |
|---|---|---|---|
| `intake_queue` | A, left | Today's cases sorted by hearing, **New intake** | `open_case {case_id}`, `open_intake_form`* |
| `case_header` | B, top | Case line, tract, hearing countdown, 5-step progress, stub warning | — |
| `suggested_questions` | B, above composer | 1–4 follow-up chips | `ask {text}` |
| `case_documents` | C, right | Tabs: Evidence (cards + excluded drawer + boundary note) · Statutes · Funds · Tract · Memo; **Open Brief** button (disabled until a brief exists, via `checks`) | `explain_exclusion {request_id}`, `ask`, `mark_memo_reviewed`, `copy_memo`*, `open_brief`*, fund intake links and memo download via the basic catalog's `openUrl` |
| `stabilization_brief` | Overlay | The printable Tenant Stabilization Brief | `print_brief`*, `close_brief`* |
| `new_intake_form` | Overlay | Initials, block, issue, hearing date/time, notice, household, % AMI, two-way bound to `/form/*`, required-field checks | `submit_intake {…form}`, `close_intake_form`* |

\* handled in the browser only (`useNavigator.ts`), never sent to the agent.

To add a component: define its API and React view in `catalog.tsx`, add it to `NAVIGATOR_COMPONENTS`, run `npm run catalog:export`, use it in `surfaces.py`, then run the checks below.

### Version note

The published renderer (`@a2ui/web_core` 0.15.0) validates renderer-side checks under the key **`checks`**; the current v1.0 spec text on GitHub spells it `@checks`. The API sends `checks`, which is what the renderer we ship accepts. Revisit when upgrading `@a2ui/*`.

## Checks

```bash
python -m pytest api/tests -q        # API + demo flow over WS and SSE; dumps every A2UI message
cd ui && npm run validate:a2ui       # runs those messages through the real A2UI MessageProcessor + navigator catalog
npm run typecheck && npm run build
```

`validate:a2ui` is what catches a surface the renderer would reject (unknown property, wrong type, bad child reference) before it reaches a browser.

## Renderer gotchas we hit

- Never unmount part of a surface while the server may still update it: tab panels, the excluded drawer and the overlays stay mounted and are hidden instead. Unmounting raced the Lit web components' update cycle (`Cannot read properties of undefined (reading 'props')`).
- Recent Chrome returns a Promise from `scrollIntoView`; an arrow-bodied `useEffect(() => el.scrollIntoView())` then crashes React on unmount. Use a block body.
- A fresh `MessageProcessor` per WebSocket connection: re-sending `createSurface` for an existing surface id is an integrity error.
- ChoicePicker `options` must be a literal array (it can't be data-bound in this renderer version).
